# Smart Campus Lost & Found Matching System

## Problem Statement
Students often lose valuable items such as wallets, notebooks, ID cards, phones, and stationery around campus. At the same time, many found items are reported separately. The absence of a smart and centralized matching system makes recovery difficult and time-consuming. This project addresses the problem by creating an intelligent lost-and-found platform that matches lost and found items based on key attributes.

## Scope of the Project
The project focuses on designing a smart campus lost and found system that allows users to record lost items and found items. The system compares these records using details like item category, color, description, date reported, and location. It then ranks possible matches to help administrators and students quickly identify the most likely owner-item pair.

## Target Users
- Students
- Campus staff
- Lost-and-found desk officers
- Security personnel
- Campus administration

## High-Level Features
- Lost item reporting
- Found item reporting
- Matching based on category, color, and location
- Keyword similarity in item descriptions
- Ranking system for possible matches
- Easy-to-use command-line interface
